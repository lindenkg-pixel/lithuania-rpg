リトアニア音楽紀行RPG
制作の経緯

AKクワイア向け・ドラクエ風ブラウザゲーム

Claude Code（AIコーディング）との対話だけで、約1週間でゼロから完成させた、スマホブラウザで遊べる単一HTMLのRPG。
  • 外部ライブラリゼロのバニラJS + HTML5 Canvas、本体は js/game.js 1ファイル（約11,300行）
  • 全10コミット（2026-04-29 〜 05-06）で「通しでクリアできる状態」に到達
  • アカウント不要・インストール不要、URLにアクセスするだけ
  • 商用ではなく、AKクワイアの仲間に「楽しみながらリトアニアと言語を学んでもらう」ための贈り物

1なぜ作ったか（コンセプト）

AKクワイアでリトアニアの音楽祭典「ダイヌシュベンテ」に向かう、という実際の文脈がベース。「教材」ではなくゲームとして遊んで完走できることを最優先に据えた。

  • 主人公はAKクワイアの一員。歌詞を忘れてしまい、リトアニア各地に散らばった4曲分の歌詞ピース（計20個）を集めて祭典で歌い上げる、という感動ストーリー
  • 通底テーマに、リトアニアが誇る実在の音楽家・画家 M.K.チュルリョーニス（故人・パブリックドメイン）を据え、要所で精霊として登場させた
  • 登場人物は実際のAKクワイアの仲間やリトアニアで出会う人々がモデル
  • リトアニア語を10単語前後だけ、会話の3択クイズで自然に覚えられる設計（欲張らない）

作り方のポイント

  1. 最初に1都市だけの縦スライスを完成させた（全機能を1都市で試す）
  2. その土台ができてから、残り都市〜エンディングを一気に展開
  3. 実際に身近な人（妻）に遊んでもらい、その場でフィードバックを反映
  4. 最後に公開・解析・表記の統一など仕上げ

3どうやって作ったか（AIとの進め方）

  • Claude Code との対話で、仕様の言語化 → 実装 → 動作確認 → 修正 を繰り返した
  • まず作りたいゲームの全体像（ストーリー・キャラ・戦闘ルール・都市構成）を仕様書として文章で固めた。これがAIへの設計指示の中心になった
  • コードはAIが書き、ブラウザで実機確認しながら細部を詰めた
  • BGMはフリー素材（CC0/CC-BY中心）、効果音はWeb Audio APIの合成音で対応
当時AIに送った個々のプロンプトのログは、Claude Code の履歴がデフォルト30日で自動削除される設定だったため現存しない。ただし設計判断は仕様書に、制作の流れは git 履歴に残っている。（今後のためにログ保持期間は延長設定済み）

4できあがったゲームの主な仕組み

  • マップ：実際のリトアニアの地理に寄せた都市配置（ヴィリニュス・カウナス・クライペダ・魔女の丘・トラカイ・シャウレイ）。都市間は駅から電車で移動（運賃ユーロ）
  • 戦闘：「歌う」が攻撃コマンド。敵HP=感動メーターで、0になると敵が泣いて勝利。3人パーティ全員をプレイヤーが操作
  • 合体技「エホーマイ」：AKクワイアがレッスン前に唱える実際の掛け声がモチーフ
  • 歌詞ピース20個：各都市で集め、5個揃うごとに新しい歌（ソーラン節／ダイナミック琉球／Mano kraštas／Kur giria）が戦闘で解禁
  • みほさん（宿屋）：移動先の各都市に毎回ワープしてくる設定で、回復・セーブ・復活を担当
  • おつかいクエスト：各都市の名物料理（キビナイ・黒パン等、実価格）を届ける文化体験要素
